I'm a Senior Unity Game Developer based in Rajkot, Gujarat, India, with 5+ years of experience at The App Guruz, where I grew from Associate Programmer to Senior Programmer.

I work across the full life of a live game: designing maintainable gameplay systems in Unity and C#, delivering real-time content with Addressables and Remote Config, building LiveOps events, integrating SDKs like Firebase, PlayFab, IAP, ads and FMOD, and keeping games smooth through debugging, memory profiling and build optimization.

I also implement the analytics and monetization side of games – event tracking, IAP stores, ad placements and Remote Config tuning – so the team can measure and improve retention and revenue.

I use AI coding agents such as Claude Code, Cursor, GitHub Copilot and OpenAI Codex every day – and I review and test every change on real devices before it reaches players.

Spec → Plan → Build → Review

02

Context engineering

Debug & refactor faster
